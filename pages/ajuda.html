FAQ

Perguntas frequentes feita em nosso Discord e suas respostas.

1. O servidor é para o Minecraft Java ou Bedrock?
R: O servidor é somente para o Minecraft Java a partir da versão 1.21.8 até 26.2

2. Qual é a versão mínima para jogar no servidor?
R: Minecraft Java 1.21.8

3. Fui banido, o que posso fazer?
R: Envie uma solicitação de remoção do banimento no formulário de contestação para o suporte

4. Onde está o IP do servidor?
R: O IP do servidor está no canal em nosso Discord

5. Como posso mandar sugestões para o servidor?
R: Envie sugestões no canal de sugestão em nosso Discord

6. Achei um bug, como posso reportar?
R: Use o canal de relatar bugs no Discord, e descreva adequadamente o bug e com uma possível prova (vídeo ou foto) para ajudar na identificação do problema.
